Exo Cinema: privacy

Exo Cinema is local-first. It has no Exo account, no ads, no analytics and no telemetry.

Exo Cinema's only Exo server is its update address, which tells it when a new version is out. Nothing you watch or do in it is sent to Exo or its developer.

What stays on this PC

Exo Cinema keeps its data in %LocalAppData%\ExoCinema, beside the app (in app), never inside it, so updates never touch it:

  • your Jellyfin sign-in (accounts.json): the server's address and name, your user name and an access token from the server, sealed with Windows' own protection for your Windows user. Your password is never stored;
  • settings.json: whether the first run is done, and the last version whose What's New you saw;
  • the interface's own storage (WebView2): your choices in Settings, the volume, the languages you picked for each show, the last server you signed in to, and a copy of Home and the title pages you opened, so they draw at once next time;
  • pictures from your server (cache\images), so Home draws before the server answers. Settings > Storage > Clear empties it;
  • the player's shaders built for your graphics card (cache\shaders), so it doesn't build them again at every start, and the poster of what's playing (cache\now-playing-…jpg) for Windows' media controls, replaced with each title;
  • link.txt: how fast streams have come in on your connection, one number, so Best picks a stream your connection carries smoothly;
  • app.log, crash.log and window-placement.json: what Exo Cinema did (timings, buffering, errors), what went wrong if it crashed, and where its window was. app.log never holds a web address, a key or your server's or add-on's name: each address is cut to its kind of file (https://…/*.mkv), so the log is safe to attach to an issue.
  • While the player is open, the title, the show and the poster of what's playing go to Windows' media controls on this PC, which show them in Windows' media flyouts and to apps that read them, such as Exo Launcher. They don't leave the PC; closing the player clears them.
  • WebView2's form memory is off: nothing you type into Exo Cinema (a server address, an add-on link) is kept by it.

Signing out forgets the sign-in. Uninstalling with Also remove my sign-in and settings deletes the whole folder; without it, the folder stays for a reinstall.

What leaves your PC

Your Jellyfin server

Exo Cinema talks to the Jellyfin server you sign in to, and only to it, for your libraries: what's in them, their pictures, search, and the video you play. When you hover the seek bar it asks for the server's preview pictures, or reads a little more of the video for its own. While you watch, it tells the server where you are in the video, when you pause and when you stop, as every Jellyfin app does, so the server keeps your place and marks what you finish as watched, and your other Jellyfin apps pick up where you left off. Watched on a title's page tells the server too. The server sees your user, your IP address, the name of this PC and a random ID Exo Cinema made for it. What it does with that is up to the server and its owner.

A stream add-on, if you add one

Settings > Playback > Stream addon is empty unless you fill it. With an add-on's address there, Exo Cinema asks that add-on for streams of what you play (the title's IMDb ID, and the season and episode), and plays from the address it answers with; when you hover the seek bar it reads a little more of that stream for the pictures. That add-on, and the host it sends you to, see your IP address.

Your Jellyfin account page

Settings > Account > Jellyfin account opens your server's own account page in your web browser.

Microsoft

Exo Cinema's interface runs on Microsoft Edge WebView2, part of Windows. WebView2 updates itself and its components through Microsoft, and may send diagnostic data according to your Windows privacy settings. If WebView2 is missing, Setup downloads Microsoft's installer from go.microsoft.com and checks Microsoft's signature on it.

Updates

As Exo Cinema opens, and only then, it asks Exo's update address (updates.getexo.app, run by Exo on Cloudflare) which release is the newest, and when a newer one is out, reads that release's list of changes (whats-new.json). If that address doesn't answer, it asks GitHub instead (github.com/UhhErix/ExoCinema/releases/latest). Settings > About > Check for updates asks at once. The update address and GitHub see your IP address while they answer, and "ExoCinema/" with the version you run; nothing else is sent. The update address keeps no logs and stores nothing about you.

When you choose Install update, Exo Cinema downloads that release's Setup and its SHA-256 through the update address, which hands the files over from Exo's own copy on Cloudflare (from GitHub, github.com and its download host, only in the minutes before a new release's copy is there). It falls back to GitHub directly if the address doesn't answer. It checks the file against that checksum and against its own version details, keeps it in %LocalAppData%\ExoCinema\updates and runs it. Setup installs over the version you have and keeps your data; the downloaded Setup is deleted the next time Exo Cinema starts.

Exo Browser: privacy

Exo Browser is local-first. It has no Exo account, no ads, no analytics and no telemetry.

Exo Browser has no server of its own. Nothing you do in it is sent to Exo or its developer.

What stays on this PC

Exo Browser keeps its data in %LocalAppData%\ExoBrowser, beside the app (in app), never inside it, so updates never touch it:

  • your settings (Boosts, Mods and your own CSS among them), open tabs, spaces and folders, history, archived tabs, bookmarks, site icons, downloads list and the extensions you added (settings.tsv, session.tsv, spaces.tsv, history.tsv, archive.tsv, bookmarks.tsv, favicons.tsv, icons.tsv, iconmiss.tsv, downloads.tsv, extensions.tsv);
  • the browser profile (Profile): cookies and sign-ins, site data, the cache, and your extensions' own data, kept by Microsoft Edge WebView2 as Edge keeps them;
  • Exo Vault (vault.exovault, and vault.exovault.bak from the save before): your logins, cards, notes and identities, encrypted (see Exo Vault);
  • a working copy of Exo Shield (Builtin);
  • a short log of what went wrong (exo.log: an update or download that failed, and where its file came from), never a page's address or a path on this PC. Copy logs, beside an error, puts it on your clipboard with Exo Browser's, Windows' and WebView2's versions, for you to paste into a report; it's never sent anywhere by itself.

A private tab (Ctrl+Shift+N) runs on a profile kept in memory only: its cookies, sign-ins and site data stay apart from your other tabs and go when the last private tab closes, and what it visits never reaches your history or saved tabs.

Settings > Privacy > Cookies, site data and cache clears cookies, every site's stored data and the cache, which signs you out of every site. Uninstalling with Also remove my data and Exo Vault deletes the whole folder; without it, the folder stays for a reinstall.

Exo Vault

  • Exo Vault is one file, encrypted with AES-256-GCM (Windows' own implementation). Its key is random and is itself locked twice: by a key made from your master password with Argon2id (256 MiB of memory, 4 passes), and, if you turn it on, by Windows Hello, through a key Windows Hello keeps for your Windows user on this PC (in its security chip when it has one).
  • Your master password is never stored. Nobody can recover the vault without it or Windows Hello, Exo included.
  • While the vault is open, its items are held in memory by Exo Browser's own interface, which has no access to the web. It locks after the time you choose, when Windows locks and when the PC sleeps, and forgets them.
  • Filling a sign-in form: a small script in each page finds sign-in fields and tells Exo Browser where they are. Exo Browser matches logins to the page's real address as WebView2 reports it, not what the page claims, and the page gets nothing until you pick a login. After you sign in, it passes what you typed to Exo Browser so it can offer to save it.
  • A password you copy is kept out of Windows' clipboard history and cloud clipboard, and cleared from the clipboard after 30 seconds.
  • Password health (weak, reused and missing 2FA) is worked out on this PC. Exo Vault never sends your passwords, or parts of their hashes, anywhere.
  • An export is one file encrypted with a password you choose. It leaves your PC only if you move it yourself.

Bringing your things from other browsers

When you choose Import (or Bring in on first run), Exo Browser reads that browser's own files on this PC: bookmarks, history, site icons, cookies (so you stay signed in), its search engine and its Chrome Web Store extensions, and, into Exo Vault, its saved passwords. From Arc it also reads its sidebar file (StorableSidebar.json) for your spaces, their colors, favorites, pinned tabs with their folders and Today tabs. For Firefox, Zen, Floorp, LibreWolf and Waterfox it reads bookmarks, history, cookies and passwords. Encrypted data is decrypted on this PC with Windows' own protection for your user. Nothing is removed from the other browser, and nothing is sent anywhere. A password export file you import is read the same way.

What leaves your PC

The sites you visit

The sites you open, and what they load, minus what Exo Shield blocks. They see what any browser sends them. Exo Browser turns on Microsoft Edge's balanced tracking prevention, and does not send the "pings" some links ask for. Notifications are off, with no setting: sites can't show them, ask to, or sign up for push messages.

Cloudflare (secure DNS)

Every address lookup (a site's name, like github.com) goes encrypted over HTTPS to Cloudflare's resolver (chrome.cloudflare-dns.com), with no unencrypted fallback, so your network and internet provider don't see which sites you look up. Cloudflare sees the names looked up and your IP address; see Cloudflare's resolver privacy policy.

Your search engine

What you type in the Bar when it isn't an address goes to the search engine you pick in Settings > General (Brave Search unless you change it; Google, DuckDuckGo, Startpage, Kagi and Bing are the others), as a normal search. A site search (a keyword such as yt, or a site's address and Tab) sends what you type to that site's own search instead, as a normal visit. Nothing is sent while you type: the Bar's suggestions come from your tabs, bookmarks and history on this PC.

Site icons

For your bookmarks and most visited sites, Exo Browser asks each site for its large icon (/apple-touch-icon.png, or the icon the page names), and asks again when you visit the site if its page names a different icon or the one kept is over a week old. These requests go to that site, or to the address its own page names for its icon (often the site's own image server), over HTTPS only, through Windows' own download service, so their address lookups use your PC's usual DNS rather than Cloudflare.

Sites you follow in live folders

When you follow a site in a live folder, Exo Browser asks that site for its feed (the RSS or Atom address its page names) 15 seconds after it starts and every 30 minutes while it runs. These requests go to that site only, through Windows' own internet service, with "ExoBrowser/" and the version you run and none of your cookies; their address lookups use your PC's usual DNS rather than Cloudflare. Delete the folder and they stop.

Twitch (Exo Shield)

To skip Twitch's ads, Exo Shield's TTV LOL PRO sends Twitch's request for a live stream's playlist (the list of video pieces, never the video) through TTV LOL PRO's proxy servers (perfprod.com) in a country where Twitch shows no ads. That request includes the channel name and the playback token Twitch gives your browser for the stream; the proxy sees it and your IP address. It looks up those servers' addresses with Cloudflare. TTV LOL PRO's ad reports are off, and it sends nothing else about you.

Chrome Web Store

Opening the Chrome Web Store is a visit to Google's site. When you add an extension, its package is downloaded from Google (clients2.google.com) with the extension's id and your WebView2 version.

Microsoft

Exo Browser runs on Microsoft Edge WebView2, part of Windows. WebView2 updates itself and its components through Microsoft, and may send diagnostic data according to your Windows privacy settings. Exo Browser turns off Microsoft Defender SmartScreen's address checks, so the pages you open are not checked with Microsoft; Exo Shield's malware lists block known bad sites instead. It also turns off the AI built into WebView2 that sites can call (its summarizer, translator, language detector and the like), so no site can make WebView2 download an AI model from Microsoft or read which models your PC has. If a site uses speech recognition (voice typing) and you let it use your microphone, WebView2 sends what the microphone hears, with the language, to Microsoft's speech service (speech.platform.bing.com), as Edge does. If WebView2 is missing, Setup downloads Microsoft's installer from go.microsoft.com and checks Microsoft's signature on it.

Exo Shield's lists

Exo Shield's filter lists are built into each release. It downloads no lists and sends nothing about the pages you visit.

The count beside the address (how many requests Exo Shield blocked on the page) is worked out on this PC and kept nowhere. Exo Shield hands the number to Exo Browser through the page itself, so that page's own scripts could read how many of its requests were blocked. Any page can tell much the same from what failed to load.

Updates

When Exo Browser starts, and every twelve hours while it runs, it asks Exo's update address which release is the newest (updates.getexo.app, on Exo's own domain, a Cloudflare Worker run for Exo). It answers with the newer of Exo Browser's latest release on GitHub and Exo's own copy of it on Cloudflare. It sees your IP address while it answers, and "ExoBrowser/" with the version you run; it keeps no logs and stores nothing about who asked. Only if it doesn't answer, Exo Browser asks GitHub itself (github.com/UhhErix/ExoBrowser/releases/latest), which sees the same. Settings > About > Check for updates asks at once.

When you choose Install update, Exo Browser downloads that release's Setup and its SHA-256 from the same place (the update address sends them from Exo's own copy on Cloudflare, and from GitHub's download host, github.com, only in the minutes before a new release's copy is there), checks the file against that checksum, keeps it in %LocalAppData%\ExoBrowser\Updates and runs it. Setup installs over the version you have and keeps your data; the downloaded Setup is deleted the next time Exo Browser starts.
